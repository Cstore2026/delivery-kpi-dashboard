نسخة V60.1 Simple Safe

مهم قبل الرفع:
1) تنزيل Backup من النسخة الحالية والاحتفاظ به.
2) رفع ملفات هذه النسخة على نفس مشروع Vercel.
3) مجرد رفع النسخة أو فتحها لا يكتب فوق بيانات Supabase.
4) التطبيق يقرأ البيانات الأونلاين ويدمجها بدون حذف السجلات الموجودة.
5) أول كتابة أونلاين تحصل فقط بعد تعديل حقيقي من مستخدم أو إنشاء Backup يدوي.
6) استخدم رابط Vercel فقط، ولا تستخدم ملف file:/// المحلي.

واجهة أمان البيانات تعرض فقط: الحالة، آخر Backup، النسخة القادمة، وثلاثة أزرار.
